Twelve screens from the PRD handoff checklist (section 19). Layout follows PRD section 12: permission-aware left sidebar, top bar with global search and scan, content area. POS and Pick & pack run full-screen for counter use. All data shown is example data.

Colours and font. No source document states VasyERP's palette or typeface; the PRD lists both as undecided (decision D1). These wireframes use the PRD's own tokens.css values exactly: primary #2f5bea, background #f7f8fa, text #1b1f27, status green/amber/red/blue, and the system UI font stack. Swapping to a final brand means editing that one file.
