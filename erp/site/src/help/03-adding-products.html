Adding products

One at a time

In Products, add a new product with its name, category, brand, GST rate and HSN code. If it comes in sizes or colours, add each option as a variant: every variant has its own SKU, price, MRP, cost, barcode and stock. Add photos if you sell online.

From a spreadsheet

If you already have a list in Excel or another program, save it as CSV and use the import in Products:

  1. Match your column headings to the ones the import screen lists.
  2. Upload the file. Nothing is saved yet: you see a preview with every row, and any problems (a missing price, a duplicate SKU) are listed by row.
  3. Fix the file and upload again, or import the rows that are correct.

Imports add products; they never change stock. Enter opening stock separately (see the stock guide).

SKUs and prices

An SKU is your own code for an item and must be unique in your store. Prices include GST. MRP is optional but printed on labels when present.
